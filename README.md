## ⚙️ Automated Build Pipeline

This repository includes a GitHub Actions CI/CD workflow ([`.github/workflows/build-resume.yml`](.github/workflows/build-resume.yml)) that:
1. Detects edits to LaTeX files (`resume/*.tex`).
2. Compiles LaTeX documents into publication-ready PDFs using XeLaTeX.
3. Automatically commits updated PDFs to the repository and updates GitHub Pages hosting.
